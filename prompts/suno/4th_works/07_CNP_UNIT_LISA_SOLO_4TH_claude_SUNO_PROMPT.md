## 📚 歌詞制作の背景・根拠

### **CNP UNIT PROJECT世界観の反映**

#### **「ここにいるよ」というテーマ**

**閉塞の中で見つけた居場所と絆**
- 外見: 行動的で明るい謎の少女
- 内面: 異世界で一人、本当は孤独だった
- "I'm Right Here" = 逃げたい場所で見つけた、かけがえのない繋がり

**カード根拠との結びつき**

#### **BT2-81 / 人間の協力者 リサ**
- **フレーバーテキスト**: 「隠れていたミタマを見つけ接触してきた謎の少女。貿易禁止命令により地表に降下することができず、脱出手段を探している。」
- **歌詞反映**:
  - Verse 1: 「コロニーの夜は静かすぎて / ひとりぼっちの部屋で見る」- 脱出を探す以前の孤独
  - Verse 2: 「あの日ミタマを見つけた時 / はじめてここで笑えた」- ミタマとの出会いの転機
  - Verse 4: 「貿易禁止で閉じ込められて / 脱出だけを夢見ていた」- カード設定の直接引用

#### **BT2-62 / ミタマ**
- **フレーバーテキスト**: 「謎の異世界に飛ばされて数週間。ミタマは謎の少女に見つかるまで、ひっそりと身を隠して暮らしていた。」
- **歌詞反映**:
  - Verse 2: 「怖がりな幽霊だけど / なんだか似ている 私と」- リサとミタマの共感
  - Bridge: 「ねえ... ミタマ... / 私ね... ずっと一人だった...」- 本音の告白

#### **BT2-67 / 向こう側からの旅人 ベアトマユ**
- **フレーバーテキスト**: 「私とウツロギリスはあんたと同じ『異世界人』さ。よろしくね！-ベアトマユ-」
- **歌詞反映**:
  - Verse 3: 「ベアトマユは笑いながら / "異世界人の仲間だね"って」- カードのセリフを直接引用

#### **BT2-64 / 人間の貿易商人 ロッズ**
- **フレーバーテキスト**: 「少女らと行動を共にする元貿易管理局の人間。貿易禁止命令を無視し無断降下を行おうとしたことで、管理局を追放されたらしい。」
- **歌詞反映**:
  - Verse 3: 「ロッズは不器用だけど / いつもそばで守ってくれる」- 仲間の支え

#### **BT2-79 / 異次元の交流（イベント）**
- **フレーバーテキスト**: 「脱出を目指す少女とミタマたちは、たどたどしくもコロニーの住人たちと交流を図り仲間を探していた。」
- **歌詞反映**:
  - Pre-Chorus: 「逃げ場のない場所で / はじめて手を繋いだ」- 閉塞の中の交流
  - Chorus: 「星の港で見つけた光 / 誰も奪えないこの絆」- 交流が絆に変わる

#### **BT2-76 / 貿易禁止命令**
- **フレーバーテキスト**: 「セイドウの侵略以来、ミッドガンはなぜか貿易を禁止し、地表への降下どころかコロニーからの出航すら許可していない。」
- **歌詞反映**:
  - Verse 4: 「貿易禁止で閉じ込められて」- 背景設定の直接反映

### **構成の工夫**

#### **A♭ major → B♭ major（温かく明るい調）**
- **A♭ major**: 温もり、包容力、ノスタルジック
- **B♭ major**: より明るく、希望に満ちた開放感
- **転調効果**: 孤独から絆へ、居場所を見つけた喜びが一段上がる瞬間

#### **BPM 130（ミドルテンポ）**
- 3rd worksの140BPMより落ち着いた温もり
- スペーシーで浮遊感がありつつ推進力もある
- 宇宙コロニーの静けさと、仲間との活気の共存

#### **Emotional → Soaring Dynamics**
- Bridge でミタマへの素直な想いを歌い上げる（ずっと一人だった）
- リサの普段見せない脆さと本音を歌唱で表現
- 感情的な歌唱から Final Chorus への感動的な解放

## 📝 制作メモ

### **Sunoへの指示ポイント**
✅ 温かくノスタルジックでありながらポップなサウンド
✅ Warm Synthwave + Space Pop + Emotional Electropop
✅ ボーカル処理: 温かいオートチューン、エモーショナル→ソアリング
✅ クリーンで柔らかいサイドチェイン（攻撃的すぎない）
✅ コズミックシマー+スターフィールドFXで宇宙コロニー感
✅ ウォームアルペジオ+ベルアクセント
✅ キーアップ（A♭ → B♭）
✅ Bridge でのドラマティックな変化（Emotional→Build→Soaring）

### **3rd worksリサソロとの統一感**
- 同じキャラクター（リサ）
- 宇宙コロニーのSF的モチーフ共通
- Synthwave系サウンドの共通基盤
- 英語フレーズの織り込み

### **3rd worksリサソロとの違い**
- **3rd「Starry adventure!」**: 冒険の興奮、脱出のスリル、140BPMの疾走感
- **4th「ここにいるよ」**: 仲間との絆、居場所の発見、130BPMの温もり
- **音楽的違い**: よりウォーム、ノスタルジック、感情的な深み。エネルギッシュ→包容的

### **4th worksでの役割**
- アルバムの「温もり」となる楽曲
- ダークなツミカソロ、エモーショナルなミライソロ、癒しのクルミソロに続く、感謝と居場所の歌
- 閉塞した環境だからこそ生まれた繋がりというポジティブなメッセージ
- 「敗北が糧となる世界」を「閉じ込められたからこそ出会えた」という形で表現

### **想定される使用シーン**
- アルバム7曲目、ソロ曲後半の温かいパート
- ライブ後半、MCで仲間への感謝を語った後
- MVでリサがコロニーの仲間たちと過ごす日常映像
- ファンが共感できる「居場所を見つける」メッセージ
