## 📚 歌詞制作の背景・根拠

### **CNP UNIT PROJECT世界観の反映**

#### **「やさしい合図」というテーマ**

**言葉を超えた繋がりの力**
- 外見: 天然で明るい、言葉は苦手
- 内面: 誰よりも他者の気持ちを感じ取る共感力
- "Gentle Signal" = 言葉がなくても伝わる、やさしい手の合図

**カード根拠との結びつき**

#### **BT1-115 / フェアリーの協力者 クルミ**
- **フレーバーテキスト**: 「少し天然だが明るい性格のフェアリー。ボディランゲージでオロチたちと意思疎通し、長く続く内戦を終わらせるために彼らを導く。」
- **歌詞反映**:
  - Verse 1: 「言葉はいらない 感じるままに / 手を伸ばして君に触れる」- ボディランゲージの表現
  - Verse 4: 「天然って言われてきたけど / それでもいい 私らしく」- 天然な性格の肯定
  - Chorus: 「Body language で heart に届く」- 核心テーマの直接表現

#### **BT2-59 / サナギ化（イベント）**
- **フレーバーテキスト**: 「ハナカのもとに無事にヤーマたちを送り届けたクルミは繭に包まれ、蛹になってしまった。」
- **歌詞反映**:
  - Verse 1: 「繭から生まれた新しい私」- 羽化後の新しい視点
  - Bridge: 花が咲くようにゆっくりでもいい - 変態のプロセスを花の比喩で

#### **BT1-96 / フェアリーの蛹**
- **フレーバーテキスト**: 「フェアリーが繭を形成し完全変態を遂げる準備を行っている姿。」
- **歌詞反映**: 繭→羽化→新しい自分という成長の前提として

#### **フェアリーの女王 ハナカ**
- **フレーバーテキスト**: 「クルミの姉で完全変態を遂げたフェアリーの一人。かつては好戦的な性格だったが、今はフェアリーたちのまとめ役になっている。」
- **歌詞反映**:
  - Verse 3: 「お姉ちゃんのハナカは昔 / 戦いばかりだったけど / 負けて初めて分かったの / 優しさこそが強さだって」- 「敗北が糧となる世界」テーマとの接続

#### **メテオラス三種族対立**
- エルフ（排他的）・フェアリー・ウッドレイス（無法）の内戦
- **歌詞反映**:
  - Verse 2: 「エルフとフェアリーとウッドレイス / ずっとケンカを続けてきた / でもみんなほんとうは同じ / 森を愛してるだけなのに」

### **楽曲コンセプト**

#### **4th worksアルバムでの位置づけ**
- **01曲（手を繋いで）**: 絆の温もり
- **02曲（希望の光）**: 前向きな闘志
- **03曲（虹色のハーモニー）**: 調和の完成
- **04曲（静かな炎）**: 内面の葛藤と静かな強さ
- **05曲（未来への祈り）**: 母との葛藤と希望
- **06曲（本曲）**: 言葉を超えた繋がり、やさしさの力

#### **3rd works「羽化の歌」との違い**
- **3rd「羽化の歌」**: 繭からの覚醒、個の変化と成長の瞬間
- **4th「やさしい合図」**: 羽化後の自分が他者を繋ぐ、やさしさが世界を変える力
- **音楽的違い**: よりドリーミーで温かく、包み込むような質感。3rdの疾走感（160BPM）→4thの穏やかな温もり（128BPM）

- **Spoken → Soaring**: 素朴な語りから力強い歌声へ

### **構成の工夫**

#### **E♭ major → F major（温かく明るい調）**
- **E♭ major**: 温かみ、包容力、夢見心地
- **F major**: より明るく、開放的、希望に満ちた
- **転調効果**: 繋がりが完成し、世界が一段明るくなる瞬間

#### **BPM 128（ミドルテンポ）**
- 3rd worksの160BPMより落ち着いた温もり
- 踊れるが急がない、花が咲くようなテンポ
- ボディランゲージの「ゆったりとした動き」を音楽的に表現

#### **Spoken → Soaring Dynamics**
- Bridgeで素朴な語り（戦えない、言葉も上手じゃない）
- しかしそれこそがクルミの強さ
- ビルドアップから Final Chorus への解放感

## 📝 制作メモ

### **Sunoへの指示ポイント**
✅ 温かくドリーミーでありながらポップなサウンド
✅ Kawaii Future Bass + Ambient + Ethereal Electropop
✅ ボーカル処理: 甘く温かいオートチューン、スポークン→ソアリング
✅ 柔らかいサイドチェイン（攻撃的すぎない）
✅ フォレストパッド+デジタルチャイムで森の空気感
✅ スパークルアルペジオ+ベルスタブ
✅ キーアップ（E♭ → F）
✅ Bridge でのドラマティックな変化（Spoken→Build→Soaring）

### **3rd worksクルミソロとの統一感**
- 同じキャラクター（クルミ）
- Kawaii系サウンドの共通基盤
- フェアリー・メテオラスの自然モチーフ
- ボディランゲージ・合図の表現

### **3rd worksクルミソロとの違い**
- **3rd「羽化の歌」**: 繭からの覚醒、個の成長、160BPMの疾走感
- **4th「やさしい合図」**: 他者との繋がり、やさしさの力、128BPMの温もり
- **音楽的違い**: よりドリーミー、アンビエント要素強化、温かく包み込む質感

### **4th worksでの役割**
- アルバムの「癒し」となる楽曲
- ダークなツミカソロ、エモーショナルなミライソロに対する温かい対比
- 争いを止める力は「やさしさ」であるというメッセージ
- 「敗北が糧となる世界」をハナカの変化で表現

### **想定される使用シーン**
- アルバム6曲目、ダーク→エモーショナルの流れを温かく包む
- ライブ中盤〜後半の癒しパート
- MVでクルミがボディランゲージで種族を繋ぐ映像
