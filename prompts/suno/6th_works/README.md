# 6th Works – アコースティック・ライトポップ 企画ノート

## アルバム概要
- **アルバム名**: 未定
- **コンセプト**: CNPキャラクターの内面を、カフェで流れているようなアコースティック寄りのライトポップで歌う。4th works の「内面を歌う」書き方と、「陽だまりの記憶」の音を組み合わせる。
- **基準曲**: 01「陽だまりの記憶」
- **規模**: 6〜8曲
- **開始日**: 2026-10-13

## 共通ルール

### 歌詞
- キャラクター1人（または1組）の内面を主役にする
- カードのフレーバーテキストから状況と性格を拾う。根拠のカードIDはプロンプトの背景欄に書く
- 固有名詞（キャラクター名・大陸名・セイドウ・神器など）は歌詞に極力出さない
- カードにない描写を足した箇所は「創作として補った箇所」に明記する

### サウンド
- 生楽器中心: アコースティックギター、フェルトピアノ、ウクレレ、ウッドベース、ブラシドラム、控えめなストリングス
- 自然な歌声。オートチューンなし
- シンセ、重いドラム、歪みは使わない
- テンポは 80〜120BPM の範囲

### 飽きさせないための変化のつけ方
- **主役の楽器を曲ごとに変える**（例: リーリーはウクレレ、ルナはピアノ）
- **大陸の色を薄く混ぜる**（カグツチ: 琴・三味線を少し／メテオラス: フルート／ミッドガン: エレピ／貿易コロニー: トイピアノなど）
- **声は全曲女性**（2026-10-17 決定）。女性ソロ、女性デュエット、5人など、人数と声質で変化をつける
- **テンポに幅を持たせる**（少し弾む曲を2曲ほど入れる）

### 05 を作るときの手がかり
- **題材候補**: 下の「題材候補」から。前回の提案ではマカミ（女性の声で歌う）を挙げた
- **まだ使っていない大陸の色**: カグツチ（琴・三味線）、メテオラス（フルート）、貿易コロニー（トイピアノ）。アクアノーヴァは 02・03、ミッドガンは 04 で使用
- **テンポ**: 弾む曲は 04 の1曲。もう1曲入れる余地がある
- **カバー**: タッチ（水彩、玉ボケ、手前の白い花のボケ、低コントラスト）は揃え、場所と構図は曲ごとに変える。使用済みは 02 昼の浜辺、03 夜の部屋の窓辺、04 晴れた坂の路地

### 制作で分かったこと
- **語り**: 語りのパートは作らず、全編を歌にする。詳細はテンプレート 5.5節「語り禁止ルール」
- **女性2人の歌い分け**: 自然な歌声の女性2人を別の歌い手として指定すると、Suno は1人の声にまとめてしまう。ソプラノとアルトを指定し、片方のパートを「ハモリなしの1声」、もう片方を「同じ音量でハモる2声」にすると、2人いることが伝わる（04 で採用）
- **サビの長さ**: 112BPM の 04 で、6行のサビだと曲が速く進みすぎた。テンポが速い曲はサビを8行（2行×4ブロック）にし、ラストサビは静かな4行のあとに8行のサビを続ける
