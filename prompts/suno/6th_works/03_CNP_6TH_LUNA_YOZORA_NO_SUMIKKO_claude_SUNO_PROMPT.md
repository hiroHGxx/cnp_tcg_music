## 📚 歌詞制作の背景・根拠

### **テーマ:「静かなままで届く」**

ルナは、夜空を眺めて静かに過ごすのが好きなキャラクター。BT2-4 では周りに合わせて青く変化したのに色が浮いて見つかってしまい、BT2-8 ではぬいぐるみになって気配を消し、誰にも気づかれないまま神器を取り返している。この2枚を並べて、「なじもうとしてもうまくいかなかった自分が、目立たないという性質のまま役に立った」を内面の軸に置いた。サビでは、その性質を夜空の端で光る星に重ねている。

02「やわらかいまま」の対になる曲でもある。02 でリーリーが歌った「隣で黙ってくれていた 君」の側から、同じ夜を Bridge で歌っている。

固有名詞（ルナ、リーリー、ミカヅキ、神器、アクアノーヴァ）は歌詞に出していない。

### **カード根拠**

#### **BT1-19 / ルナ**
- **フレーバーテキスト**: 「ウサギのルナは、夜空を眺めて静かに過ごすのが好き。」
- **歌詞反映**:
  - Verse 1:「にぎやかな輪の 少し外側 / うなずくだけで 夜が更けていく」- 静かに過ごす性格
  - Chorus:「夜空のすみっこで 光る星は」、Final Chorus:「今夜も空を 見上げている」- 夜空を眺める

#### **BT2-4 / ブルー**
- **フレーバーテキスト**: 「青い姿に変化したルナ。一見、海の多いアクアノーヴァでの擬態に役立ちそうだが、微妙に色が浮いていてすぐに見つかってしまう。」
- **歌詞反映**: Verse 2「ここの色に なじみたくて / 青い色を まとってみたの / だけど少しだけ 色が浮いて / すぐに誰かに 見つかってしまう」- カードの出来事をほぼそのまま歌詞にした

#### **BT2-8 / ぬいぐるみ**
- **フレーバーテキスト**: 「ぬいぐるみの姿に変化することで気配を完全に消したルナ。誰にも気づかれず、ついにミカヅキから神器を取り返した！」
- **歌詞反映**: Verse 3「息をひそめて 動かずにいた / ちいさなぬいぐるみの ふりをして / 誰も私に 気づかないこと / はじめてそれが 力になった」- 曲の核になる場面

#### **BT1-27 / 奥義:ルナの跳躍！**
- **フレーバーテキスト**: 「高く飛び上がり、急降下して繰り出すキック技。」
- **歌詞反映**: Pre-Chorus 2「高く跳ぶのは 一度でいい / その時が来るまで 待てるから」- 跳躍を、普段は静かに待つ性格と結びつけた

#### **BT2-14 / 神器の真相**
- **フレーバーテキスト**: 「ミカヅキから神器を取り返したルナとリーリーは茫然とした。それは本来の神器とは遠くかけ離れた贋作だったのだ。」
- **歌詞反映**: Bridge「取り返した光は にせものだった / 言葉が何も 出てこなくて」- 茫然とした場面

#### **BT1-14 / ギャラクシー**
- **フレーバーテキスト**: 「星々の力を身に纏ったルナの姿。」
- **歌詞反映**: Final Chorus「星のひかりを そっとまとって」

#### **BT2-5 / ルナ、BT2-9 / リーリー**
- **フレーバーテキスト**: 「…ルナとリーリーは、密かに取り返す計画を立てている。」「…気を逸らされたミカヅキは、リーリーとルナの接近に気づかなかった。」
- **歌詞反映**: Bridge とラストサビの「君」はリーリーを指す。二人で動いていたことの根拠

### **創作として補った箇所**（カードに記述なし）
- 「にぎやかな輪の 少し外側」「星の名前は たくさん知ってる」: 静かに夜空を眺める性格からの想像
- 「ここの色に なじみたくて」: カードでは擬態が目的。歌詞では「周りに溶け込みたい気持ち」として読み替えた
- 「うまく混ざれない 私のままで / できることなんて あるのかな」: ブルーの失敗のあとの心情
- Bridge「だから黙って 隣に座った」「君は少し 笑ってくれた」: 贋作判明後の場面の解釈。02 の「隣で黙ってくれていた」と揃えた
- サビの「迷った誰かの帰り道を教える星」: ルナ自身を星にたとえた比喩で、カードの出来事ではない
- 一人称「私」と女性ボーカル: カードに性別の記述はなく、プロジェクトの既定（女性ボーカル）に従った

### **音楽的方向性**
- **ジャンル**: アコースティック寄りのライトポップ。6th works の音のまま、ピアノを主役にして夜の曲にする
- **BPM 84 / D major**: 01（98）、02（100）より遅くして、アルバムの中の静かな場所にする。転調はしない
- **音色**: フェルトピアノが主役。ウッドベース、ブラシドラム、ナイロン弦ギター、チェロ、控えめなストリングス。星の表現にグロッケンとチェレスタを少しだけ使う。イントロとアウトロに遠い波音を入れ、02 と同じ海辺の夜だと分かるようにする
- **ボーカル**: オートチューンなしの自然な歌声。02 より落ち着いた低めの温度で、全編を歌にする（語り・ささやきは使わない）
- **起伏**: 輪の外側にいる自分（Verse 1）→ なじめなかった（Verse 2）→ 星のたとえ（Chorus）→ 目立たないことが力になった（Verse 3）→ 贋作の夜に隣に座る（Bridge）→ 自分の場所で空を見上げる（Final Chorus）
