## 📚 歌詞制作の背景・根拠

### **テーマ:「やわらかいまま強い」**

リーリーは、おっとりした人気者でありながら、いざというときだけ巨大化して仲間を守るキャラクター。さらに BT2-10 では、ぷにぷにと弾むソーダグミの体がミカヅキの猛攻を受け止めている。この2枚から「硬くならなくても守れる」「やわらかさは弱さではない」を内面の軸に置いた。

固有名詞（リーリー、ルナ、ミカヅキ、神器、アクアノーヴァ）は歌詞に出さず、4th works のソロ曲と同じく感情を主役にしている。

### **カード根拠**

#### **BT1-15 / リーリー**
- **フレーバーテキスト**: 「パンダのリーリーはCNPの人気者。おっとりしているが、いざとなると巨大化して仲間を守る頼もしさも持っている。」
- **歌詞反映**:
  - Verse 1:「のんびり屋だねって みんなが笑う」- おっとりした性格
  - Verse 2:「誰かの背中が 震えていたら / この体は 勝手に動き出す」- いざとなると守る
  - Verse 3:「変わらない声で 私の名前」- 人気者

#### **BT1-23 / 奥義:リーリーの巨大化！**
- **フレーバーテキスト**: 「見る見るうちに、見上げるほどに巨大化したリーリー。」
- **歌詞反映**: Chorus「見上げるほどに 大きくなるのは / 君が小さく 泣いた夜だけ」- カードの言い回しを引用し、巨大化の理由を内面から描いた

#### **BT1-17 / 海水、BT1-20 / シロクマ、BT2-2 / ピンク**
- **フレーバーテキスト**: 「パンダのリーリーは、海の姿にも変化できる特別な力を持っている。」「シロクマのような力強さと優雅さを併せ持つ姿に。」「ショッキングピンクに変化したリーリーは、ひときわ目を引く華やかさ。」
- **歌詞反映**: Verse 3「海の色にも 雪の色にも / はじけるピンクにも なってみたけど」、Chorus「形を変えても / まんなかにある ものは同じ」

#### **BT2-10 / ソーダグミ**
- **フレーバーテキスト**: 「ソーダグミのような姿に変化したリーリー。ぷにぷにと弾む体表は、ミカヅキの猛攻を意外なほど受け止めてみせた。」
- **歌詞反映**: Verse 4「ぷにぷに弾む 頼りない体 / いちばん強い嵐を 受け止めてた」- 曲の核になる場面

#### **BT2-14 / 神器の真相**
- **フレーバーテキスト**: 「ミカヅキから神器を取り返したルナとリーリーは茫然とした。それは本来の神器とは遠くかけ離れた贋作だったのだ。」
- **歌詞反映**: Pre-Chorus 2「やっと取り返した光が / にせものだと知った日も」、Bridge「何も取り戻せなかったのかな」

#### **BT1-19 / ルナ**
- **フレーバーテキスト**: 「ウサギのルナは、夜空を眺めて静かに過ごすのが好き。」
- **歌詞反映**: Pre-Chorus 2「隣で黙ってくれていた / 君だけは ほんものだった」- 静かな相棒としてのルナ

### **創作として補った箇所**（カードに記述なし）
- 「波の音を聴きながら お昼寝してる」: おっとりした性格と舞台（海の大陸）からの想像
- 「こわくないわけじゃないよ / 足はちゃんと すくんでる」: 巨大化の前の心情
- Bridge「空っぽの手のひらを 握ってくれた」: 贋作判明後の場面の解釈
- 一人称「私」と女性ボーカル: カードに性別の記述はなく、プロジェクトの既定（女性ボーカル）に従った

### **音楽的方向性**
- **ジャンル**: アコースティック寄りのライトポップ。6th works 01「陽だまりの記憶」に近い、生楽器中心の穏やかな音にする
- **BPM 100 / F major**: 弾むが急がないテンポ。転調はせず、ラストサビは編成を少し厚くするだけにとどめる
- **音色**: 指弾きのアコースティックギター、フェルトピアノ、ウクレレ、ブラシドラム、控えめなストリングス。波の音を薄く入れて海辺の午後を出す
- **ボーカル**: オートチューンなしの自然な歌声
- **起伏**: のんびりした日常（Verse 1-2）→ 守る理由（Chorus）→ 気づき（Verse 4）→ 贋作の喪失（Pre-Chorus 2、Bridge）→ それでも残ったもの（Final Chorus）
